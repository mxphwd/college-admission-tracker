Completely free, lightweight native menu bar app for tracking college admissions.

Features:
+ Completely free w/ no in-app purchases whatsoever.
+ Built natively for Apple Silicon support.
+ Clean, glassy design.

You can add up to three application periods + one early action for each school.

Manually add the .app file to Login Items setting for it to auto-boot on startup.
